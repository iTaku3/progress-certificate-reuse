# 完了観測選定の限定命題

2026-09-08。研究問題を具体化するための参照解析。hitting set／監督制御の既知手法と区別して、学術的新規性を主張する資料ではない。

## 設定

ジョブ集合をV、同時実行を禁止する部分集合族をH、終了を信頼して観測できるジョブ集合をOとする。Hの各要素は2件以上。全ジョブは一回限りで、実行は独立な任意の有限時間後に終了する。既知の上限はない。ジョブの開始を制御でき、終了以外の手段で非観測ジョブの終了を知ることはできない。先行制約や締切はない。

目的は、どの許容される実行時間でも安全性を保ち、全ジョブをいずれ開始すること。実際の全完了は有限実行時間仮定から従う。

**命題：この目的を達成できるのは、OがHの全要素と交わる場合、かつその場合に限る。**

## 十分性

まずOのジョブを一つずつ開始し、その真の終了通知を待つ。単独では禁則集合を満たさず、全て有限時間で終了する。続いてV\Oのジョブを開始する。Hの各要素にはOの終了済みジョブが含まれるため、残りの同時実行でも禁則集合の全員が実行中になることはない。全員を開始する有限の方策となる。

この構成は存在を示すための保守的な方策で、最大並列性や最短時間を主張しない。

## 必要性

Oと交わらない禁則集合hがあるとする。hの全ジョブを開始する方策は、その最後のジョブをある有限時点で開始しなければならない。しかし、それまでに観測した履歴からは、hの先に開始したジョブが終了したかを区別できない。hの全員がその時点まで実行中で、その直後以降に有限時間で終了する挙動も仮定に適合する。その挙動では禁則に違反する。最後の開始を永久に待てば全開始の目的を満たせない。

任意の固定待ち時間でも既知上限のない完了を断定できない点が本質。上限を契約に加える場合はこの必要性は変わる。

## 計算上の意味

費用付き観測対象の選定は、この限定クラスでは重み付きhitting setになる。二者禁則だけなら重み付きvertex cover。組合せ最適化への帰着やセンサ選択の難しさは既知。重要なのは一般の非同期契約も同じ条件で解けると拡大解釈しないこと。

ゲーム実装は、非観測の開始済みジョブを「まだ実行中かもしれない」と保持する。観測対象の終了待ちは、現在実行中の観測対象のどれか一つが次に終了する分岐とする。この待機の進行は有限実行時間・通知到達仮定を組み込んだものであり、単なる安全ゲームの無限待機と異なる。状態の「開始数＋観測済み終了数」は各手で増え、有限である。

## 適用範囲を超える例

- 同じジョブを繰り返す場合、一回の全開始に足りる観測集合が、次の周期にも足りるとは限らない。二者競合でAだけ終了観測できる場合、A完了後Bを始めれば一回は実行できるが、Bの終了を知る方法がなければ次のAを安全に始める根拠がない。
- 完了時間に既知の上限があれば、観測なしでも安全な待ち時間を使える場合がある。
- 別の部品の応答が終了を間接的に保証する場合、その相関を無視すると観測点を過大に要求する。
- 先行制約・取消し・複数段階の効果・通知消失があれば、同じhitting set条件だけでは足りない。

N1の研究対象は、こうした部品契約の違いを反映し、どこまで局所的に必要な観測・制御条件を導けるか。N2の一般的なセンサ選択問題を別名称で新規性と主張しない。
